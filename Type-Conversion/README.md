# Type Conversion

This folder contains Java programs demonstrating type conversion.

## Topics Covered
- Implicit Type Casting (Widening)
- Explicit Type Casting (Narrowing)
- Primitive Data Type Conversion
- Type Promotion in Expressions
- Real-world Examples

## Programs
- Byte to Int
- Int to Double
- Double to Int
- Float to Long
- Char to Int
- Type Promotion Examples
